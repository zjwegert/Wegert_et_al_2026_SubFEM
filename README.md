Scripts for the paper "A discontinuous finite element method for hydroelastic analysis of submerged structures" by Zachary J. Wegert, Oriol Colomés, Michael H. Meylan, Ngamta Thamwattana, Vivien J. Challis:

> Zachary J. Wegert, Oriol Colomés, Michael H. Meylan, Ngamta Thamwattana, and Vivien J. Challis (2026). "A discontinuous finite element method for hydroelastic analysis of submerged structures". [arXiv:...](https://arxiv.org/abs/...).

## Installation
The package can be installed using the Julia package manager as follows:
1. Clone the repository
2. Start Julia inside the repo (e.g., run `julia --project` from a terminal in the repository root)
3. Install the `SemiAnalyticWECs.jl` package dependency via `] add https://github.com/zjwegert/SemiAnalyticWECs.jl`. This should automatically install the other dependencies as usual.

## Usage
The numerical experiments in the journal paper can be run via the `.jl` files in `/scripts`.
